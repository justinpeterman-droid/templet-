# Phase Files

This folder holds the working files for each phase of the build, `PHASE_00`
through `PHASE_12`. They are referenced by `docs/MASTER_BRIEF.md`.

Each phase file should follow the same shape so they're predictable to work from:

- **Goal** — one sentence on what this phase produces.
- **Why this phase matters** — the reasoning, so shortcuts are resisted.
- **Decisions / inputs** — choices to make before prompting Cursor.
- **Prompts for Cursor** — pasted one at a time.
- **Definition of done** — the checklist that says the phase is complete.
- **Common pitfalls** — what tends to go wrong here.
